# 365-Day Bible Reading Plan Generator

This project contains tools to generate and execute a Balanced 365-Day Bible Reading Plan. It focuses on presenting the original texts (Hebrew Masoretic Text for OT, Greek Textus Receptus/Majority Text for NT) alongside literal English translations (KJV, LSV).

## Overview

The project aims to provide a complete Bible reading plan that finishes exactly on December 31st, balancing daily reading times between the Old Testament, New Testament, Psalms, and Proverbs.

### Key Files

*   **`generate_readings.py`**: A Python script that calculates the daily schedule.
    *   Uses dynamic verse counting to ensure completion on Dec 31.
    *   Respects Hebrew versification (which differs from KJV in books like Leviticus and Psalms).
    *   Generates `readings.json`.
*   **`fetch_readings.py`**: A utility to download scripture data from `api.bible`.
    *   Requires an API Key.
    *   Organizes output into dated folders (e.g., `data/0201/`).
    *   Handles parallel translation fetching.
*   **`readings.json`**: The master schedule generated by the script.

## Setup Instructions

1.  **Prerequisites**: Python 3.x installed.
2.  **API Key**: You need a free API Key from [api.bible](https://scripture.api.bible/).
3.  **Environment Variable**: Set your API key in your terminal before running the fetch script.

    **PowerShell:**
    ```powershell
    $env:API_BIBLE_KEY = "your_32_char_api_key"
    ```

    **Bash/Linux:**
    ```bash
    export API_BIBLE_KEY="your_32_char_api_key"
    ```

## Usage

1.  **Generate Plan** (Optional, `readings.json` is already included):
    ```bash
    python generate_readings.py
    ```

2.  **Fetch Readings**:
    *   Single Day: `python fetch_readings.py --day 0201`
    *   Month: `python fetch_readings.py --month 02`
    *   Full Year: `python fetch_readings.py --all`

Data will be saved to the `./data` directory (or directory specified by `--out`).
