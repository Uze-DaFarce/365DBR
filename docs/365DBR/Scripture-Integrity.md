# Scripture integrity (non-negotiable)

Present the data we have. Do not add to or subtract from Scripture.

- **Blank is honest.** If a translation (LSB, LSV, KJV, Hebrew, Greek) has no text for that slot, show empty. Do not invent.
- **Hiding is not honest.** If one translation has a real verse, show it even when another translation (including Hebrew/Greek) lacks that number or that text.
- **“Other translations” includes Hebrew and Greek.** Differing versification is expected. Do not drop English LSB/KJV/LSV verses because the original used a different BCV, and do not drop original verses because English used a different BCV.
- **Verse body is scripture words only.** No titles, footnotes, USFM/USX styles, or notes glued into the verse.
- **Keys stay native to the edition.** Look up LSB by LSB/English USX ids, original by org ids. Do not copy one edition’s id onto another edition’s text.
