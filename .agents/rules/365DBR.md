# 365DBR (Non-Negotiable)

- **Static Architecture:** Public site is static files on GoDaddy (`https://mt-sin.ai/365DBR/`)—never a live Postgres, public API, cPanel MySQL, or Option B. Local cache generates static files for production (speed is a side effect). Canonical: `docs/365DBR/Hosting-and-Runtime.md`.
- **Translations & Retired Tools:** LSB is default focal English when present in the day pack; LSV fallback. Never add LSB to the retired api.bible fetcher or run `apps/365DBR/reference/retired-api-bible/`.
- **Text & Word Study Integrity:** Show real verses; never hide them. Titles live in `titles[]`, not verse bodies. Word study `Aa` is on for Hebrew/Greek tokens; never invent EN↔Strong's maps or global-wipe tokens. Greek `strong_number` values are uncertified until each uniquely matches its source row.
- **Audio & Doc Guardrails:** Read `docs/365DBR_AGENTS.md` before changing `verseMap`, `loadDailyBread`, or `playVerse`. Do not re-research Phases 1–3 or read Blueprint/schema/migration docs unless a design choice requires it; check `docs/365DBR/Handoff-Next-Session.md` only if needed.
- **Extreme QA Vectors & Viewports:** Beyond date-seeded tests, verify extremes: Song of Solomon 8:14 (widest header), 2 Thess 3:18, 1 Thess 5:28, Ps 119:176, all 5 bookmarks, one OT and one NT. Check viewports `320`, `390×844`, `430`, `768`, `1280`, and the What We Know panel (`~449`).
