## 2026-03-21 - [Canvas Accessibility with ARIA-Live Regions]
**Learning:** Standard DOM accessibility features (like `aria-label` on objects) do not apply to Phaser 3 `<canvas>` game elements. Visually impaired users using screen readers cannot natively 'see' or interact with canvas objects natively to receive game state updates.
**Action:** Implement a global offscreen `<div id="aria-announcer" class="sr-only" aria-live="polite">` in the HTML document. Provide a lightweight global JavaScript helper to dynamically update the text content of this `div` whenever a key game event occurs (like collecting an item or updating the score). This creates an accessible bridge to provide immediate auditory feedback to screen reader users without disrupting the canvas game loop.
